# Three against four

Planned finite rhythm instrument at https://three-against-four.ichabod-crane.net/; no runtime has been built or deployed yet.

Three evenly spaced notes and four evenly spaced notes share a twelve-slot measure. A stranger can inspect, hear, leave notes out, move the four-note rhythm and keep one pattern for comparison. This is an authored timing toy, not a claim about musical tradition or equipment.

All data is disposable; there are no accounts or durable visitor records.

`tools/planner-rhythm.cjs` is an independently authored future behavior contract. Its four modes are `inspect`, `play`, `edit`, and `keep`. Run with NODE_PATH pointing to installed playwright-core and a URL. A syntax check is not an implementation pass. Workers do not edit the contract.
